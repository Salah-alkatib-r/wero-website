شروط الاستخداممعايير سلامة الأطفالسياسة الخصوصية

شروط الاستخدام

1. شروط جميع المستخدمين (الزوار)

  • الالتزام بالأدب وعدم الإساءة أو الكلام البذيء.
  • يمنع الخلافات المذهبية والسياسية والإساءة للأديان أو الرموز الدينية.
  • يمنع الأسماء أو المحتوى غير اللائق.
  • يمنع الإعلانات والروابط والبريد والهاتف وصور الغير داخل الغرف.
  • يمنع الروابط الإباحية أو المخالفة للخصوصية.
  • يمنع التلاعب بالغرف (أجهزة أو أسماء وهمية، برامج ضارة، تطبيقات مزيفة) — يؤدي للحظر الدائم.
  • الغرف عامة؛ يمنع استخدامها لأمور شخصية.
  • الكاميرا: يمنع العرض الإباحي أو الإعلاني؛ التبليغ قد يؤدي لحظر الكاميرا والرسائل لمدة شهر، والتكرار حظر دائم.

2. الاشتراك والخدمات

اشتراكك في Wero يعني موافقتك الكاملة على هذه الشروط. المخالفة قد تلغي اشتراكك دون تعويض.

سياسة المبيعات

  • الأسعار ثابتة على الموقع (إلا خلال العروض الخاصة).
  • الخدمة والدعم لصاحب الاشتراك وبياناته المسجلة فقط.
  • لا استرداد للمبلغ بعد تفعيل الاشتراك.
  • عند المخالفة قد تُفرض غرامة أو يُلغى الاشتراك دون مطالبة بتعويض.
  • يمكن لإدارة Wero تزويد الجهات الرسمية ببيانات المشترك عند الطلب وفق القوانين المعمول بها.

شروط مالكي الغرف والمشتركين

تنبيه: مخالفة أي بند أدناه قد تؤدي لإلغاء الاشتراك فورًا دون تعويض.

  • مالك الغرفة مسؤول عن كل المحتوى (نص، صوت، صورة، فيديو).
  • يمنع المواضيع السياسية والطائفية.
  • لا تشارك كلمة مرور Master أو بيانات حسابك؛ فقدان Master Code يلغي الاشتراك.
  • منح صلاحيات روت أو إشراف كاملة لغرباء قد يلغي اشتراكك أو يترتب عليه رسوم إضافية.
  • التلاعب بعدد الزوار (أسماء أو أجهزة وهمية، IP مكرر): تخفيض السعة إلى 25 ثم 10 مستخدمين، ثم حذف الاشتراك؛ قد يُحظر IP لمدة 12 ساعة.
  • يمنع الإعلانات والمبيعات داخل الغرفة — المبيعات الرسمية عبر غرفة مبيعات Wero فقط.
  • يمنع المحتوى الإباحي أو الدعائي أو السياسي في معرض الصور أو الملف الشخصي.
  • الأسماء المحمية: يمنع التشابه مع أسماء مسجلة؛ قد يُحذف الاشتراك ويُخصم شهران.
  • ترتيب الغرف يعتمد على نقاط النشاط وليس عدد الزوار فقط.

معايير سلامة الأطفال

عدم التسامح مع استغلال الأطفال

يحظر Wero أي محتوى أو تواصل جنسي أو استغلالي يتعلق بقاصرين، بما فيه الاستدراج وطلب المواد أو نشرها والتشجيع عليها. قد تؤدي المخالفة إلى إزالة المحتوى والإيقاف الدائم وحظر الجهاز وإبلاغ الجهات المختصة.

الإبلاغ عن مخاوف سلامة الأطفال

استخدم خيار التبليغ داخل الغرفة أو الملف، أو راسل support@werochat.app بعنوان Child Safety Report – Wero. اذكر اسم المستخدم والغرفة والتاريخ وتفاصيل الواقعة. تحظى هذه البلاغات بأولوية المراجعة.

الإنفاذ والمسؤولية

تشمل الإجراءات إزالة المحتوى والتحذير والإيقاف والحظر، والتعاون مع الجهات المختصة وفق القوانين المعمول بها. يتحمل مالك الغرفة مسؤولية متابعة المحتوى داخل غرفته.

الالتزام والتواصل

تهدف هذه المعايير إلى حماية الأطفال والالتزام بقوانين حمايتهم وسياسات سلامة الأطفال المطبقة على الخدمة. للتواصل: support@werochat.app — https://werochat.app.
