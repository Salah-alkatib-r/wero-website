Static Cloudflare Pages website. Existing Pages Functions and root-panel bindings remain unchanged.
APK files belong in the GitHub release android-2019, not in the Pages source tree (25 MiB per-asset hosting limit).
`downloads.json` remains unpublished until the four release assets have been checked by name, size and SHA-256.
The model catalog is a search aid. It never infers Android OS bitness from a phone's marketing name; unavailable browser hints fall back to the universal APK.
